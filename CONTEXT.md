# Domain glossary

## Profile

A named planning perspective selected without authentication. Anyone with server access may switch profiles.

## Task

A shared unit of work. Its content, dependencies, project labels, and completion state are the same for every profile.

## Daily Plan

A profile's placement and ordering of shared tasks for one date. Focus, Queue, and review outcomes belong to the profile's Daily Plan.

## Review

A profile-specific decision pass over that profile's unfinished Daily Plan.
